Task 1 implemented: a periodic table where every element is a
square with a letter (symbol) in the center. On mouse hover the
symbol is replaced by the element's atomic number
(e.g. O -> 8). Nothing else: no names, no colors.

================================================================
DECISIONS (all made autonomously, as requested)
================================================================
1. Stack: plain Vanilla JS + HTML + CSS. No frameworks, no build
   step, no npm packages. Keeps it minimal and fast.
2. Server: Node, built-in http module (server.js).
   Run with a single command: node server.js — the way the user
   is used to. No dependencies to install.
3. Port: 1429 (3000 is already in use).
4. Hover: the symbol is REPLACED by the number in the same square
   (not a tooltip, not a corner badge) — as requested.
5. Styling: only squares with a single centered letter.
   No colors, no names added.
